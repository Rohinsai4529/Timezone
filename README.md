# 🌍 Timezone App

A simple React application that shows the **current time,Sunrise,Sunset times will be  shown and timezone based on country** using the GeoNames API.

## Features

* Search timezone by country
* Displays current local time
* Real-time API data
* Clean and responsive UI

## Tech Stack

* React (Vite)
* JavaScript
* GeoNames API

## How to Run Locally

Clone the repository

Install dependencies

```
npm install
```

Start the development server

```
npm run dev
```

Open in browser:
http://localhost:5173
